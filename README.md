# 🎮 GameRent

Sistema moderno de locação de consoles desenvolvido em **PHP Orientado a Objetos**, utilizando autenticação, armazenamento em JSON e interface moderna com Bootstrap.

---

# ✨ Preview

O sistema possui:

- 🔐 Tela de login moderna
- 🎮 Gerenciamento de consoles
- 📦 Sistema de aluguel e devolução
- 👑 Controle de permissões de administrador
- 💾 Persistência de dados em JSON
- 🌌 Interface gamer premium
- 📱 Layout responsivo

---

# 🚀 Tecnologias Utilizadas

- PHP 8+
- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- JSON
- Programação Orientada a Objetos (POO)
